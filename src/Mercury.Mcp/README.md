# Mercury MCP Server

MCP server for Claude with persistent RDF store at `~/Library/SkyOmega/stores/mcp/` (macOS), `~/.local/share/SkyOmega/stores/mcp/` (Linux; `$XDG_DATA_HOME` replaces `~/.local/share` when set) or `%LOCALAPPDATA%\SkyOmega\stores\mcp\` (Windows). Provides SPARQL query, update, and store management tools.
