# DrHook MCP Server

MCP server for .NET runtime inspection. 25 tools spanning EventPipe observation, ICorDebug-native stepping, breakpoint management with conditional/hit-count/logpoint policies, locals inspection with one-level object and array expansion, the debug state as a PNG, a GUI debuggee's own window as a PNG, session lifecycle (stop / detach / kill), debuggee console + logpoint-output drains, and substrate-anomaly streaming. Backed entirely by `DrHook.Engine` (BCL + P/Invoke + source-gen COM). Each debug session runs in a debugger worker of its own, `drhook-worker` (`src/DrHook.Worker`, carried in `worker/` beside drhook-mcp), which drhook-mcp starts for the session and relays the session's tools to ([ADR-016](../../docs/adrs/drhook/ADR-016-debugger-resilience-and-recovery.md) 6.7); drhook-mcp itself loads no debugger. Tool names follow established IDE-debugger convention per [ADR-010](../../docs/adrs/drhook/ADR-010-mcp-tool-surface-redesign.md).
